# 🏛️ Landing Page – Escritório de Arquitetura

Projeto de landing page desenvolvido como desafio técnico, com foco em layout moderno, responsividade e captura de leads integrada ao Google Sheets.

---

## 🎯 Objetivo do Projeto
Criar uma landing page funcional para um escritório de arquitetura, permitindo que usuários solicitem orçamento através de um formulário integrado ao Google Sheets, sem necessidade de backend.

---

## 🚀 Funcionalidades
- Layout moderno e responsivo
- Seção institucional (hero)
- Métricas de credibilidade
- Formulário de contato
- Integração com Google Sheets via Sheet Monkey
- Armazenamento automático dos leads

---

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- Google Fonts (Inter)
- SheetMonkey
- GoogleSheets
- GitHub

---

## 🔗 Integração com Google Sheets
O formulário envia os dados diretamente para uma planilha do Google Sheets utilizando a API do Sheet Monkey, permitindo captura automática de leads sem backend.
